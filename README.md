# ResearchKit

A lightweight browser-based toolkit for academic writing and research planning.

## Deploy on Vercel

This is a static website. Upload `index.html` to the root of a GitHub repository, then import that repository in Vercel. No build command or output directory is needed for the static HTML version.

## Current features

- Word and character counter
- Text case converter and cleaner
- APA 7 reference builder
- Sample size estimator
- PICO question builder
- Abstract word-limit checker
- Percentage calculator
- AI prompt builders for abstract writing, paraphrasing, and research planning
- Lightweight grammar-pattern checker
- PRISMA flowchart builder with SVG/PNG export
- Systematic review planner
- Browser-local reference manager
- Basic APA 7, Vancouver, and Harvard reference formatting

## Important notes

- AI prompt builders do not call a live AI model yet.
- References are stored locally in the user's browser and are not synced to a server.
- Check all calculations, references, and review counts before using them in academic work.
